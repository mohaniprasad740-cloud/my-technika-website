# TECHNIKA 6.0 website

A responsive, single-page website built with HTML, CSS and vanilla JavaScript.

## Run locally
1. Extract the ZIP file.
2. Open the `technika6_website` folder in VS Code.
3. Open `index.html` in your browser, or use the VS Code Live Server extension.
4. No npm install or build step is required.

## Before publishing
- Replace the official-site placeholder destinations with the confirmed registration, brochure, sponsor and social URLs if those have separate links.
- Add the full official event list and verified event rules/timings when available. Only Code Buster's supplied time and venue are shown as confirmed; other event details are marked to be announced.
- Add approved event/organiser photos if you have them.

## Deploy
You can deploy this static site on Vercel by importing the folder/repository. Choose the "Other" preset and leave the build command and output directory empty (or set output directory to `.`).
